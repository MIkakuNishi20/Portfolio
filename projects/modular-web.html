Modular Web Architecture

Focus: PHP Modularization, Reusable Components, and CSS Layouts

Overview

Demonstrating DRY (Don't Repeat Yourself) principles by refactoring monolithic web application files into modular navigation, header, and footer includes.

Component Structure (PHP)

<?php
// index.php
$pageTitle = "Home | Personal Portfolio";
include_once 'includes/header.php';
include_once 'includes/navbar.php';
?>

<main class="content">
    <h1>Welcome to My Portfolio</h1>
</main>

<?php
include_once 'includes/footer.php';
?>
